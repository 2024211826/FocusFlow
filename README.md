# FocusFlow

一个使用原生 HTML、CSS 和 JavaScript 编写的番茄钟与今日任务管理 Demo，适合作为 Git 团队协作练习项目。

## 功能

- 25 分钟专注与 5 分钟休息计时
- 计时器开始、暂停和重置
- 添加、完成和删除今日任务
- 使用浏览器本地存储保存任务与专注数据
- 响应式布局，支持电脑和手机浏览

## 运行方式

项目没有第三方依赖，可以直接双击 `index.html`，也可以在项目目录启动本地服务器：

```bash
python -m http.server 8000
```

然后访问 <http://localhost:8000>。

## 文件结构

```text
.
├── index.html   # 页面结构
├── style.css    # 页面样式与响应式布局
├── script.js    # 计时器、任务管理及本地存储逻辑
└── README.md    # 项目说明
```

## 适合贡献者完成的小改动

- 增加深色主题切换功能
- 增加 15 分钟长休息模式
- 修改页面标题或今日提示

## 浏览器支持

推荐使用最新版 Chrome、Edge、Firefox 或 Safari。
